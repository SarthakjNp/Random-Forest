### 🚢 Titanic Survival Prediction using Random Forest
This project applies the Random Forest Classification algorithm to predict the survival of passengers aboard the Titanic. The Titanic dataset is a classic binary classification problem that includes both numerical and categorical variables.

### 📁 Dataset
Name: Titanic.csv

Source: Kaggle / Titanic ML competition dataset

Description: Contains details of passengers such as age, fare, class, sex, and port of embarkation, along with whether or not they survived.

### 🧠 Project Objective
Build a predictive model using the Random Forest algorithm by following these steps:

## Load the dataset
Import and prepare the dataset for processing.

## Exploratory Data Analysis (EDA)
Understand data distributions, relationships, and patterns.

## Handle missing values
Clean the dataset by imputing or removing null values intelligently.

## Preprocess categorical variables
Encode non-numeric features to make them machine-learning compatible.

## Split the dataset
Divide the data into training and testing sets for model validation.

## Train a Random Forest Classifier
Fit the model on the training data to predict survival.

## Evaluate the model
Use metrics such as accuracy, confusion matrix, and classification report to assess performance.

## Tune hyperparameters
Optimize the model using GridSearchCV or similar techniques to enhance accuracy.

### 🛠 Technologies Used

Python 3.x
Pandas & NumPy for data manipulation
Matplotlib / Seaborn for EDA
Scikit-learn for model building and evaluation

### ✅ Outcomes
Achieved a strong baseline accuracy using the Random Forest model.

Improved performance after hyperparameter tuning.

Gained insight into the importance of features affecting passenger survival.
